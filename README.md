# Loyalsoldier's clash-rules for JMS

An override config file to use [Loyalsoldier's clash-rules](Loyalsoldier) for the official Mihomo / Clash.Meta YAML subscription of Just My Socks.

Includes some personal preferences:

- Removed "Auto" proxy group.
- Rename "JMS" -> "Just My Socks"
- Add "APNs" proxy group

---

This override config file is compatible with both Stash and Clash Verge Rev.
